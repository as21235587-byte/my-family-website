🌳 My Family Tree Website

A simple and personal Family Tree Website created using HTML and CSS to digitally showcase family members, their photographs, occupations, and contact information.

---

📌 About the Project

My Family Tree is a basic web development project that represents family members in two main categories:

- Elders
- Youngers

The website uses HTML navigation links so that users can quickly move to the information section of a particular family member.

The project also includes an About Family section describing the importance of family, along with a simple footer.

---

✨ Features

- 🌳 Family Tree homepage
- 👴 Elders section
- 👦 Youngers section
- 📸 Family member photographs
- 💼 Occupation details
- 📞 Click-to-call contact links
- 🔗 Anchor-based navigation

🚀 How to Run

Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Make sure "index.html" and "styles.css" are in the same folder.
4. Open "index.html" in any modern web browser.

Using VS Code

1. Open the project folder in VS Code.
2. Open "index.html".
3. Install the Live Server extension.
4. Right-click "index.html".
5. Select Open with Live Server.

---

☁️ GitHub Deployment

This project can be hosted using GitHub Pages.

Steps

1. Create a new GitHub repository.
2. Upload:
   - "index.html"
   - "styles.css"
   - "README.md"
3. Open repository Settings.
4. Go to Pages.
5. Select:
   - Source: Deploy from a branch
   - Branch: "main"
   - Folder: "/ (root)"
6. Click Save.

After deployment, GitHub Pages will provide a website URL.
